# 02 — Problema a Resolver

> Fonte: `spec.txt` — pergunta 2

## Problema principal
**Fragmentação das ferramentas e informações** utilizadas no treinamento esportivo.

### Fragmentação de ferramentas
O treinador usa plataformas diferentes para:

- Prescrição de treinos
- Coleta de atividades
- Análise de desempenho
- Comunicação
- Organização dos atletas
- Controle financeiro
- Demais tarefas administrativas

### Fragmentação de dados
Os dados do atleta ficam distribuídos entre sistemas:

- **Em plataformas esportivas:** ritmo, frequência cardíaca, distância.
- **Coletados manualmente (mensagens/formulários):** sono, fadiga, percepção de esforço, dores.

## Problema secundário
A maioria das plataformas **apresenta os dados, mas não os transforma numa visão integrada do atleta**.

## Como o Pulsar pretende resolver
- Centralizar informações **objetivas e subjetivas**;
- Permitir que sejam analisadas **conjuntamente**;
- *(produto final)* Ampliar a análise para vídeos e imagens, com visão computacional e ML para análise técnica e biomecânica.

## Mudança de lógica pretendida
> De: *"aqui está o treino que você precisa fazer"*
>
> Para: *compreender como o atleta está respondendo ao treinamento e adaptar os próximos estímulos.*
