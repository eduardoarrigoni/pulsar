# 05 — Pitch Comercial (apresentação ao cliente)

> Fonte: `spec.txt` — pergunta 5

## Posicionamento
> **O Pulsar é um ecossistema inteligente para treinadores e atletas que transforma dados de treinamento em decisões.**

## Para o treinador
Em uma única plataforma:

- Planejar os treinamentos
- Organizar seus atletas
- Acompanhar a execução
- Analisar desempenho
- Compreender como cada atleta está respondendo aos estímulos

## Para o atleta
Uma experiência mais completa:

- Visualizar sua evolução
- Receber treinos personalizados
- Assistir a explicações em vídeo
- Registrar percepção de esforço, sono, fadiga e dores
- Acompanhar seu desenvolvimento

## Fontes de dados
- **Início:** integração com o **Strava** como principal fonte externa.
- **Depois:** outras plataformas, dispositivos esportivos e novas fontes de informação.

## Longo prazo
Uso de IA, Machine Learning e visão computacional para analisar não apenas os dados da atividade, mas **vídeos e imagens do movimento do atleta**.

## Promessa final
Integrar **gestão + treinamento + dados + relacionamento + inteligência esportiva** em um único ecossistema.
